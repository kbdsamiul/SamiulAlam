---

## How to Update the Site

1. Open `https://samiulalam.github.io/admin.html`
2. Login with your password
3. Add/edit publications, talks, photos, awards
4. Click **Export & Deploy → Generate & Download index.html**
5. Upload the new `index.html` to this repo (replace the old one)
6. Site updates live within 1–2 minutes ✅

---

## Admin Panel Features

- 📄 **Publications** — Add journal articles, book chapters, mark under-review papers
- 🎤 **Talks & Posters** — Log conferences, upload poster images
- 📷 **Photo Gallery** — Upload field/lab/conference photos with captions
- 🏅 **Awards** — Add honors with logo/badge images
- 🔬 **Experience** — Update research positions
- 📚 **Workshops** — Log trainings and short courses
- 👤 **Hero/Profile** — Edit name, title, affiliation
- 💾 **Backup** — Export/import all data as JSON

---

## Tech Stack

- Pure HTML, CSS, JavaScript — no frameworks, no build tools
- Hosted on GitHub Pages (free)
- Admin data stored in browser localStorage
- All content baked into a single `index.html` on export
